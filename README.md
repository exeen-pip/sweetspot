# sp — sweet spot ♡

Личный центр учёбы для Windows: автоплан дня, музыка, анки, обои-мотивация.
Настоящее окно-приложение (Electron), всё живёт локально на ноуте.
Никаких облаков, подписок и «премиум-функций».

---

## 🫶 Быстрый старт (Windows, npm не нужен!)

1. Создай новую пустую папку, например `sp` (хоть на рабочем столе).
2. Скачай в неё **3 файла** из этого репозитория — наведи на файл, кнопка **«Download raw file»**:
   - [`GET-APP.bat`](GET-APP.bat)
   - [`sp.zip.part00`](sp.zip.part00)
   - [`sp.zip.part01`](sp.zip.part01)
3. Запусти **`GET-APP.bat`** — он сам склеит части, распакует и откроет приложение.
4. Дальше всегда запускай `sp-app\sp.exe` — сделай ярлык на рабочий стол и живи.

> Если батник что-то напишет — там будет видна конкретная причина (например,
> браузер недокачал часть — тогда удали обе и скачай заново).
>
> SmartScreen один раз может спросить про неподписанный exe →
> «Подробнее» → «Выполнить в любом случае». Это нормально.

**Обои/мотивация — кнопка ✦** · **полка виджетов — кнопка +** · **настройки — ⚙**

### Управление столом (окна как на ноутбуке)
- **тяни за шапку** — окно переезжает куда угодно, окна свободно перекрывают друг друга,
  клик по окну поднимает его наверх
- **тяни за уголок в правом нижнем углу** — размер в любую сторону, любой
- **двойной клик по шапке** — свернуть/развернуть
- **правый клик по шапке** — цвет ♡, сброс места, архив
- 8 палитр в настройках: coquette, беж, баттер, персик, лаванда, мята, ночь, e-girl

## Что умеет
- **помойка-вход** — кидай как попало («кр по химии завтра в 19:00», «сочинение в пятницу»),
  разложит по предметам, датам и тегам; по желанию — нейро-парсер на бесплатном ключе Gemini/Groq
- **планировщик** — сам собирает день: школа (уроки из edupage или вручную), сон, кривая энергии,
  дедлайны, приоритеты и *желания* (пинтерест — это законный слот в плане, а не враг)
- **разминки** вместо помодоро — настраиваемый интервал (по умолчанию раз в час)
- **фокус-страж** — видит активное окно Windows, мягко возвращает, если уплыла из учебных окон
- **anki** — через AnkiConnect: сколько карточек ждать сегодня, повторения прямо тут
- **плеер** — локальные файлы, скачивание треков и плейлистов по ссылке (нужен yt-dlp)
- **обои ✦** — поиск картинок (Unsplash → Openverse, бесплатно, без ключей),
  «на обои ♡» или «мотивация ✦» на весь экран
- **часы, заметки, калькулятор, инбокс** — 9 виджетов на полке «+», всё перетаскивается,
  ложится под твой размер и красится в свой цвет

## Опциональные усилители
- **плейлисты по ссылке**: поставь [yt-dlp](https://github.com/yt-dlp/yt-dlp#installation-windows)
  (`winget install yt-dlp`), перезапусти sp
- **Anki**: поставь [Anki](https://apps.ankiweb.net) + плагин **AnkiConnect** (код `2055492159`)
- **нейро-парсер**: бесплатный ключ — [aistudio.google.com](https://aistudio.google.com/apikey) (Gemini)
  или [console.groq.com](https://console.groq.com/keys). Ключ хранится только на ноуте

## Запуск из исходников (для разработки)
1. Поставь [Node.js LTS](https://nodejs.org).
2. Дважды кликни **`start.bat`** — сам поставит движок и запустит sp. Либо руками:
```bat
npm install
npm start
```

## Разработка
```bash
npm test   # логика планировщика и помойки
npm start  # запустить приложение
```

## Приватность
Активные окна фокус-страж читает только названием, только пока запущена сессия, и только
на этом ноуте. Ключ нейронки и все данные — локальный файл в `%APPDATA%/sp-sweet-spot/data.json`.
