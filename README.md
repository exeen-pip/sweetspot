# sp — sweet spot ♡

Личный центр учёбы для Windows. Настоящее окно-приложение (Electron), живёт на ноуте,
все данные — локально в JSON. Никаких облаков, подписок и «премиум-функций».

## Что уже умеет
- **помойка-вход** — кидай как попало («кр по химии завтра в 19:00», «сочинение в пятницу»),
  разложит по предметам, датам и тегам; по желанию — нейро-парсер на бесплатном ключе Gemini/Groq
- **планировщик** — сам собирает день: школа (уроки из edupage или вручную), сон, кривая энергии,
  дедлайны, приоритеты и *желания* (пинтерест — это законный слот в плане, а не враг)
- **разминки** вместо помодоро — настраиваемый интервал (по умолчанию раз в час)
- **фокус-страж** — видит активное окно Windows, мягко возвращает, если уплыла из учебных окон
- **anki** — из-за AnkiConnect: сколько карточек ждать сегодня, повторения прямо тут
- **плеер** — локальные файлы, скачивание треков и плейлистов по ссылке (нужен yt-dlp)
- **часы, стикеры, калькулятор** — и всё перетаскивается, меняет размер и прячется;
  3 темы (coquette / neutral / dark+pink), свой акцент и фоновая картинка

## Запуск (Windows)
1. Поставь [Node.js LTS](https://nodejs.org) (галка «Add to PATH» стоит сама).
2. Скачай папку репо (Code → Download ZIP) и распакуй.
3. Дважды кликни **`start.bat`** — первый запуск поставит движок (пара минут), потом откроется окно sp.

## Кто усиливает фичи (по желанию)
- **плейлисты по ссылке**: поставь [yt-dlp](https://github.com/yt-dlp/yt-dlp#installation-windows) —
  например `winget install yt-dlp`, потом перезапусти sp;
- **Anki**: поставь [Anki](https://apps.ankiweb.net) + плагин **AnkiConnect** (код `2055492159`);
- **нейро-парсер**: бесплатный ключ — [aistudio.google.com](https://aistudio.google.com/apikey) (Gemini)
  или [console.groq.com](https://console.groq.com/keys). Ключ хранится только на ноуте.

## Превращаем в sp.exe
```bat
npm install
npm run dist
```
Готовый установщик появится в папке `dist/`.

## Разработка
```bash
npm test   # логика планировщика и помойки
npm start  # запустить приложение
```

## Приватность
Активные окна фокус-страж читает только названием, только пока запущена сессия, и только
на этом ноуте. Ключ нейронки и всё остальное — локальный файл в `%APPDATA%/sp-sweet-spot/data.json`.

## Портативная сборка (Windows, без npm)

1. Зайди в [Releases](https://github.com/exeen-pip/sweetspot/releases) и скачай `sp-portable-win-x64.zip`.
2. Распакуй в любую папку (правый клик → «Извлечь всё»).
3. Запусти `sp.exe`. Всё. Никакого npm, Node.js и настроек безопасности не нужно.

Альтернатива для запуска из исходников: `start.bat` — теперь сам ставит зависимости,
долечивает Electron и запускает его напрямую, минуя npm.
