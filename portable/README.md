# sp — portable сборка для Windows (без npm)

1. Скачай в эту папку все 3 файла со страницы репозитория (кнопка **Download raw file**):
   - `GET-APP.bat`
   - `sp-portable-win-x64.zip.part00`
   - `sp-portable-win-x64.zip.part01`
2. Запусти `GET-APP.bat` — он склеит, распакует и запустит приложение, потом приберёт за собой.
3. Дальше всегда запускай `sp-app\sp.exe` (можно ярлык на рабочий стол).

npm, Node.js и какие-либо настройки безопасности Windows не нужны.
